Machine Learning

Three-Branch Ensemble

01

Tabular Ensemble

Random Forest, XGBoost, and Gradient Boosting are trained on structured wallet features. Best model selected via cross-validated F1/AUC. Outputs fraud probability [0,1].

Weight in fusion50%
02

Graph Neural Network

GraphSAGE-style GNN treats wallets as nodes and transfers as edges. Learns embeddings capturing proximity to blacklisted wallets, cluster membership, and multi-hop exposure.

Weight in fusion30%
03

Autoencoder (Anomaly)

Trained on normal wallet behavior. High reconstruction error = anomalous. Catches novel attack patterns (new flash-loan variants, wash trading) without requiring fraud labels.

Weight in fusion20%

Feature Engineering

Feature Taxonomy

📊 Transactional
  • Transaction amount & frequency
  • Failed transaction count
  • Average gas fee
  • Burst activity score
👛 Wallet
  • Wallet age (days since creation)
  • Current balance
  • Unique counterparties
📜 Contract
  • Smart contract call count
  • Rug pull token interaction flag
  • Flash loan usage detection
🪙 Token
  • ERC-20 token transfer volume
  • ERC-721/1155 NFT transfers
🕸️ Network (GNN)
  • Graph centrality (degree / betweenness)
  • Cluster risk score
  • Hops to blacklisted wallet
🔍 Anomaly
  • Autoencoder reconstruction error
  • Percentile rank among all wallets
